# Pivníček 2.0

A simple beer counter and pub tab for Android. Count beers with a swipe, keep track of a tab, and view a rough alcohol estimate. The estimate is not a measurement and does not indicate that it is safe to drive. For adults only.

## Installation

1. Open the [latest release](../../releases/latest) on an Android device and download `android-build-release-signed.apk`.
2. If Android asks, allow your browser or file manager to install unknown apps.
3. Open the downloaded APK and follow the installation prompts.

The APK is signed for release and targets Android `arm64-v8a`. Install updates from the same signing key; uninstalling the app removes its locally stored data.
